# Учебный проект "Электронная торговля"
## Контекст
Большая часть разработки использует ООП-подход для создания своих сервисов, а также работы с данными, которые представляют собой сущности или объекты со своими параметрами и методами. В рамках этих домашних заданий мы проработаем использование классов и объектов на основе популярной темы e-commerce.

E-commerce  — электронная торговля, или электронная коммерция. На данном этапе работы мы не будем реализовывать систему платежей, однако подготовим всё для того, чтобы у нас появилось ядро для интернет-магазина. В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.

## Модуль main
Отвечает за основную логику проекта и связывает функциональности между собой.
## Использование разработанных функций
### Модуль category
1. Category - класс категорий товаров.
### Модуль product
1. Product - класс характеристик товара
### Модуль utils
1. Функция loads_category_and_product_data_from_json загружает данные по категориям и товарам из файла JSON.
2. Функция create_object_from_json конвертирует полученные данные из файла JSON в объекты классов.
## Тестирование
Проект использует библиотеку pytest для тестирования. Все основные модули проекта покрыты тестами, что позволяет обеспечивать стабильность и надежность кода. Тесты находятся в папке tests, и их можно запустить командой:
```
pytest --cov=src --cov-report=html
```
### Покрытие тестами
 1. Покрытие тестами составляет более 80%.
 2. Основные модули имеют высокий уровень покрытия, подтверждающий корректность их работы.
 3. Отчет о покрытии можно найти в папке htmlcov, открыв файл index.html в браузере.
### Подробности
 1. Тесты включают проверку всех критических функций.
 2. Используются фикстуры для различных сценариев.
